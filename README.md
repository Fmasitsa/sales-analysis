#Beauty Business Performance Analysis

Analyzed the sales, expense, services and profitability of a beauty business using data from when the business commenced in April 2024 to August 2026.
The analysis was conducted to understand the financial performance of the business, identify major expense areas, determine which service and periods generates the most revenue, and provides insights that can support better business desicions.


##Process

- Cleaned and prepared sales & expense data for analysis using google sheets
- Developed an interactive Power BI with KPIs & relevant visualizations
- Used DAX for analysis, Star scheme style model and cross filtering features to enable exploration of the data
- Identified trends and patterns in the data to provide valuable insights for decision making


##Tools Used
- Microsoft Excel/ Google Sheets
- Microsoft Power BI
-  DAX
-  Data Visualization
-  Pivot tables and Explanatory Analysis
